# ProSmash

A professional **B2B sports commerce platform** for wholesale and institutional trade,
serving schools, sports academies, colleges, retailers and other institutional buyers,
supplied by manufacturers, wholesalers, distributors and dealers.

**Initial target market:** India.

## Platform Surfaces

| Portal | Audience |
|---|---|
| Super Admin | ProSmash operations team — approvals, catalog governance, supplier procurement |
| Supplier Portal | Manufacturers, wholesalers, distributors, dealers (registration requires admin approval) |
| Business Buyer Portal | Schools, academies, colleges, retailers, institutional purchasers |

## Project Status

Initialization & planning stage. **No technology stack has been selected yet**;
no application code exists. See `CLAUDE.md` for working rules and
`docs/` for evolving project documentation.
