## 1. Programme scope

Three deliverable sets, commissioned together, usable independently:

| Set | Purpose | Volume (initial) |
|---|---|---|
| A — Product studies | Catalogue cards, product detail galleries | Every live SKU at launch (preview set: ~12 SKUs → plan for 150–400 at catalogue build-out) |
| B — Institutional action imagery | Public-site heroes and section bands only | 8–12 selects |
| C — Detail/texture studies | PDP gallery secondary frames, category headers | 2–4 per category |

## 2. Set A — Product studies (the catalogue standard)

**Ground:** Chalk `#FFFFFF` or light-grey seamless (`#F4F4F2` max) — one
ground per category, never mixed within a category. No gradients, no
coloured sweeps, no lifestyle props in catalogue frames.

**Light:** soft key + fill, natural-feeling directional light; shadows
present but shallow (flat-plane doctrine — the product sits, it does not
float); no hard colour casts. White balance locked per session.

**Ratios & framing:**

- Master frame **4:3 landscape** (card + PDP main image standard,
  library §4/§7). Safe margin ≥ 8% on all sides.
- Deliver a **1:1 crop** from the same shot for compact/thumbnail use.
- Product fills 70–85% of frame height. Consistent camera height per
  angle set; focal length 50–85mm equivalent (no wide-angle distortion).

**Angle set per category** (every SKU in a category gets the same set):

| Category | Primary | Secondary | Detail (set C overlap) |
|---|---|---|---|
| Cricket — bats | Face ¾ view, handle up-right | Full spine profile | Grains/sticker zone, handle grip |
| Cricket — balls, protection, bags | Front ¾ | Back or open view | Seam/stitching, padding section |
| Football / Basketball / Volleyball | Hero ¾ with valve at 4 o'clock | Panel/texture flat | Surface grain macro |
| Badminton — racquets | Full frame vertical | Throat & grip close | String bed macro |
| Badminton — shuttles | Tube upright + one shuttle beside | Shuttle solo | Feather/cork macro |
| Tennis | Racquet full + ball pair | Grip close | String bed macro |
| Athletics (hurdles, shots, mats) | ¾ assembled | Folded/adjusted state | Mechanism/joint |
| Gym & fitness | ¾ pair arrangement | Single unit profile | Knurling/texture macro |
| Indoor games | Board/table ¾ | Playing surface top-down | Edge/corner detail |
| Outdoor games | Assembled ¾ | Packed/kit state | Fixing detail |
| Sportswear | Flat lay, squared, consistent fold | Fabric drape detail | Weave/print macro |
| Accessories | ¾ on ground line | In-context-of-kit frame | Closure/material macro |

**Sets and kits** (jersey sets, ball boxes, kit bags with contents): one
additional "count frame" showing the full quantity — institutional buyers
buy quantities; the photo should prove the set.

**Technical delivery:** RAW + edited TIFF + web JPEG/AVIF; longest edge
≥ 3000px; sRGB; no watermarks, no retouch that misrepresents the product
(colour accuracy over beauty). File naming per ASSET-INVENTORY.md
(`prod-{sku}-{angle}.{ext}`), delivered to the asset intake folder — never
directly into `media/` or the repo by hand.

## 3. Set B — Institutional action imagery (public site only)

**Subjects:** real Indian institutional sport — school cricket nets at
practice, academy badminton courts, college athletics, equipment rooms and
warehouse racking. Athletes and staff **at work**; no posed high-fives, no
camera-aware smiling groups, no US-context sports, no cartoon/3D renders.

**Treatment:** natural directional light, high contrast, true colour with a
slightly deepened shadow floor. Every select must survive the **flat Ink
overlay at 55–70%** with Chalk display type over it — shoot with negative
space for type (left-third or lower-third clear).

**Crop:** compose for the **16° diagonal** — motion entering the frame
along that axis; deliver full-bleed 16:9 and 21:9 crops plus a 4:5
portrait crop for mobile heroes.

**Consent & context:** institutional locations and recognisable people
require signed releases (minors: guardian + institution release). Shot
list to be approved by the owner before the shoot day.

## 4. Set C — Detail & texture studies

Macro/close frames per category (string beds, seam stitching, willow
grain, knurling, fabric weave) on the same grounds as Set A. Used as PDP
gallery frames 2–4 and as quiet category-header textures. Same light
discipline; depth of field may be shallow but the subject plane stays
sharp.

## 5. Licensing & usage requirements (commissioning terms)

1. **Work-for-hire or full exclusive buyout** of all delivered frames —
   perpetual, worldwide, all media (web, app, print, advertising), with
   the right to crop, overlay and recolour per brand treatment. No
   per-use, per-seat or time-limited licences.
2. Photographer retains portfolio-use rights only if the owner agrees in
   writing; no third-party stock resale of ProSmash frames, ever.
3. Model/property releases delivered with the files for every
   recognisable person and private location (Set B).
4. No embedded stock, composites or AI-generated elements inside
   delivered frames; RAW files are part of the deliverable and remain the
   property of ProSmash.
5. Licence records and contracts filed under `brand/guidelines/` with a
   register entry per delivery batch (mirroring the font-licence pattern
   in `brand/fonts/LICENSES.md`).

## 6. Acceptance checklist (per batch)

- [ ] Ground, angle set and margins match §2 for the category
- [ ] Colour-accurate against physical sample (owner or ops sign-off)
- [ ] 4:3 master + 1:1 crop + (Set B) 16:9/21:9/4:5 crops present
- [ ] File naming per ASSET-INVENTORY.md; EXIF stripped on web variants
- [ ] Releases & licence paperwork complete
- [ ] No prohibited treatments (gradients, neon, compositing, AI artefacts)

## 7. Sequencing with the build

T3 (public full press) consumes Set B first and the preview-SKU slice of
Set A (~12 products currently in the sample catalogue). Until then the
interim CC-labelled imagery remains, clearly marked. Swapping assets is a
content operation, not a code change — the card/gallery frames already
reserve the 4:3 ratio.
